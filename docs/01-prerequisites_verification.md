# Historical verification record — not a tutorial

This file intentionally contains no account identifiers, bucket names, connection names, token paths,
IAM policy values, screenshots, or step-by-step commands. Earlier private operator evidence was
removed because it was specific to one Snowflake account and could not be safely followed by another
reader.

Use the maintained public path instead:

1. [01 — Prerequisites](01-prerequisites.md) for feature, account, AWS, and local-tool requirements.
2. [02 — Snowflake setup](02-snowflake-setup.md) through [10 — Metabase](10-metabase.md) for the
   linear build procedure and its verification gates.
3. [12 — Validation](12-validation.md) for the final Snowflake readiness checks.
4. [Openflow recovery](../openflow/RECOVERY.md) for private flow export, restoration, and the
   repeat-demo boundary.

Do not treat historical status claims as current account state. Run the documented read-only checks
and stop at any failed gate. Private deployment evidence belongs outside this repository.
